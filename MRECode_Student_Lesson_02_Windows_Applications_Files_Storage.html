01
المذكرة الأساسية

الشرح الكامل

واجهة Windows التي تستخدمها كل يوم

Desktop مساحة العمل، وStart للوصول للتطبيقات، وTaskbar للتطبيقات المثبتة والمفتوحة، وSystem Tray للصوت والشبكة والبطارية والوقت.

اختصارات مفيدة: Win فتح Start، Win+D سطح المكتب، Alt+Tab التنقل بين البرامج، Win+E فتح File Explorer.

File Explorer والمسار Path

الملف له اسم + امتداد + مكان. مثال: C:/Users/Student/Documents/Report.docx. الجزء الأخير هو اسم الملف وامتداده، وما قبله هو المسار.

المجلد Folder حاوية لتنظيم الملفات ومجلدات أخرى. التنظيم الجيد يقلل الأخطاء ويوفر وقت البحث.

عمليات إدارة الملفات

  • Create: إنشاء Folder أو File.
  • Rename: اسم واضح مثل Sales_Report_October.xlsx.
  • Copy: نسخة جديدة ويبقى الأصل.
  • Cut/Move: نقل الملف من مكان إلى آخر.
  • Delete: غالبًا إلى Recycle Bin ثم يمكن Restore.
  • Search: بالاسم أو النوع أو جزء من الاسم.

الامتدادات File Extensions

الامتداد يساعد Windows في معرفة نوع الملف والتطبيق المناسب. أمثلة: .docx Word، .xlsx Excel، .pptx PowerPoint، .pdf PDF، .jpg/.png صور، .zip ملف مضغوط.

نصيحة: لا تغيّر الامتداد يدويًا كطريقة لتحويل الملف؛ استخدم Save As/Export أو أداة تحويل مناسبة.

التخزين والضغط والنسخ الاحتياطي

قد تخزن على SSD داخلي أو USB أو Cloud. ملف ZIP يجمع ملفات متعددة في ملف واحد وقد يقلل الحجم. النسخة الاحتياطية Backup تعني وجود نسخة إضافية يمكن استعادتها لو ضاع الأصل.

قاعدة عملية: الملفات المهمة لا تعتمد على نسخة وحيدة في مكان واحد.

02
خلاصة ثابتة للمراجعة في البيت

خلاصة بصرية + صورة توضيحية

✦ اكتب وافتكر

  • Win+E = File Explorer • Win+D = Desktop • Alt+Tab = Switch apps
  • Copy يحتفظ بالأصل • Move ينقل الأصل
  • امتداد الملف يحدد النوع، وليس مجرد جزء شكلي من الاسم.
  • اسم ملف جيد = معنى + تاريخ/نسخة عند الحاجة.

04
قبل الامتحان أو المراجعة

ملخص المذاكرة

✓ File Explorer هو مدير الملفات والمجلدات في Windows.
✓ Copy ≠ Move، وRecycle Bin قد يسمح بالاستعادة.
✓ الامتدادات مثل .docx و.xlsx و.pdf تساعد في تحديد نوع الملف.
✓ ZIP مناسب للتجميع والمشاركة وليس بديلًا عن Backup.

مصطلحات الدرس

Path
المسار الذي يحدد مكان الملف.
Extension
الجزء مثل .pdf أو .xlsx الذي يوضح النوع.
Recycle Bin
مكان مؤقت للملفات المحذوفة غالبًا.
ZIP
صيغة أرشيف لتجميع/ضغط الملفات.
Backup
نسخة إضافية للاستعادة عند الفقد.
